# План разработки

## Что уже есть (сентябрь 2026)

Этап 1 (MVP автопостинга) завершён и переработан в модульный движок «парсим весь день → вечером выжимка».

### Модульность
- **Профили ниш** (`src/TgAutoposter.Infrastructure/Profiles/*.json`, переопределение в `./profiles`): промпты фактчека/дедупа/генерации/картинок, маркеры «новость/шум», правила классификации, шаблоны AI-поиска, стартовые типы публикаций, источники, футер, расписание, реестр талантов. У канала поле `ProfileKey` (`gaming`, `vtubing`).
- **Коллекторы** по одному на вид источника (`Services/Collectors`): Reddit (OAuth → анонимный JSON → wspanel → RSS), RSS/Web, AI-поиск (Polza), YouTube (RSS канала), Telegram (t.me/s превью, через wspanel или прокси), X (wspanel `read` в залогиненном Chrome). `CompositeContentCollector` маршрутизирует по `SourceKind`.

### Конвейер
1. **Ingest** (`IngestWorker`, каждые N минут, без AI): источники → `SourceCandidates` (дедуп по внешнему id/хешу). Не зависит от дневных лимитов.
2. **Сюжеты** (`StoryClusteringService`, после каждого сбора): эмбеддинги или Jaccard по заголовкам + общие таланты → `Stories` с важностью, лид-инфоповодом, признаком «срочно».
3. **Генерация** (`AutopostingPipeline`, `AutopostingWorker` или вручную): берёт из пула кандидатов/сюжета → дедуп → фактчек → текст → картинка → очередь/публикация.
4. **Дайджест** (`DigestService`, `DigestWorker`, раз в день в `Channel.DigestTimeLocal`): модель ранжирует сюжеты дня → пост-выжимка + до N черновиков «вероятных постов».

### Админка
Страницы: Обзор, **Сегодня** (сюжеты, инфоповоды по источникам, дайджест сейчас), Очередь, Каналы (+профиль, +дайджест), Источники (все виды), **Таланты**, Типы, Промпты, Расписание, История, Расходы, Пользователи, Интеграции.

## Что нужно для запуска витубинг-канала
1. `SEED_DEFAULT_PROFILE=vtubing` для новой базы или создать канал с тематикой «Витубинг» в админке.
2. Polza.ai с балансом (`POLZA_*`) — иначе фактчек/дедуп/дайджест работают на локальных эвристиках, посты не генерируются.
3. Reddit: `REDDIT_CLIENT_ID/SECRET` (script-app) — без них анонимный доступ с многих IP даёт 403/429.
4. wspanel (`WSPANEL_*`): ключ с правом `cdp.attach`, id стола с Chrome, залогиненным в X. Даёт X-источники и чтение t.me без прокси.
5. Telegram-бот и чат модерации (`TELEGRAM_*`), как раньше.
